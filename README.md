# ASCII ⇄ HEX 互转台

清水混凝土风格的纯前端工具，文本与十六进制字节码双向实时互转，支持文件导入导出，全部计算在浏览器本地完成。

## ✨ 功能特性

- 双向实时转换：文本（UTF-8 编码）⇄ HEX，输入即转；HEX 输入兼容 `0x` 前缀与空格 / 冒号 / 逗号等写法，非法字符自动忽略并提示
- 分隔符（空格 / 无 / 冒号 / 逗号 / 换行）与十六进制大小写可切换，一键交换两侧内容
- 文件导入：任意文件读取为字节（大文件仅载入前 256KB），支持拖拽到面板导入
- 文件导出：可导出 `.txt`、`.hex` 文本或 `.bin` 二进制，文件名可自定义
- 实时统计字符数 / 字节数，含非 ASCII 字节、非 UTF-8 序列时给出提示
- 内置 ASCII 速查表（DEC 32–126，可折叠展开）

## 🚀 使用方法

纯静态单文件页面，无需构建。直接用浏览器打开 `index.html` 即可使用，离线可用。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript（单文件，零依赖）
- Web API：`TextEncoder` / `TextDecoder`、`navigator.clipboard`、`Blob` 下载

## 📁 目录结构

- `index.html` — 全部页面、样式与逻辑
